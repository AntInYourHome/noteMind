### 🔍 深度分析

**是什么**：腾讯朱雀实验室开源的 AI 红队测试平台 A.I.G（Apache 2.0），定位"AI 全栈自查工具"：从底层 AI 基础设施到上层 Agent 工作流的一站式攻防评估。本期入选的直接信号是**周星增 +97（6,176→6,273）且保持高频发版**（v4.5.1→v4.6.1 两个月四版），在降级采集日仍是四层全栈中跨层覆盖最完整的活跃项目。

**技术机制**（五层扫描栈，规则规模均经 README 核实）：
1. **AI Infra 扫描**——对运行中服务指纹识别并匹配 CVE：146 个 AI 组件、2000+ 条 CVE 规则，覆盖 Ollama/ComfyUI/vLLM/n8n/Triton（对应 L3 基础设施层）；
2. **MCP Server 与 Agent Skills 扫描**——支持源码上传或远程 URL、无需运行实例，按 14 大类风险分类（L2 供应链）；
3. **Skill 扫描 CLI（aig-skill-scan）**——可嵌入企业 CI/CD，9 类风险（T01-T09）对齐 SkillTrustBench，v4.5.2 还加了 .pyc 字节码绕过检测（对抗"编译规避扫描"）（L2）；
4. **Agent Scan**——多智能体自动化框架评估 Agent 工作流，支持 Dify/Coze 等平台，10 个 OWASP 技能映射 ASI 风险（L2）；
5. **越狱评测**——v4.5.1 新增 Many-Shot/PAIR/GOAT/ActorAttack 四种多轮攻击，跨模型对比（L1）。v4.6.0（08-26）又新增 **LLM API 投毒检测**和 Agent-Scan 变异引擎重构——检测"给你的 LLM API 中转下毒"是新方向。

**证据强度**：中上。官方 Skill 扫描给出具体模型实测 F1（Claude Opus 4.6 达 0.9848，另有 GLM 5.1/Gemini 3.5 Flash/Kimi 2.6/DeepSeek v4 Flash），规则数量可复核，发版节奏真实可查；但需注意三点：README 明示**平台无鉴权、不应部署公网**（自身安全尚未闭环）；F1 由厂商自测；Pro 版（aigsec.ai）需邀请码，开源版与商业版能力边界不明。

**四层定位**：罕见的 L1+L2+L3 三层横跨平台（缺 L4 物理执行），且与统一图谱两条横切主线直接相关——供应链证明（MCP/技能扫描是"装前检测"，与 NVIDIA SkillSpector、snyk agent-scan 同赛道，国内生态里基本是独一份）和后果等级（Infra 扫描打的是"AI 服务自身的 CVE"，这一层常被 LLM 安全叙事忽略）。收敛信号：上周 Top1（ZK 谓词证明网关）解决"Agent 间信任"，本周 AI-Infra-Guard 高热代表"平台自查"——**防御重心正从"单点模型防护"转向"全栈可验证"**。

**影响与对策**：① 企业防御者——可作为 AI 资产盘点+红队自查的低成本起点（Docker 一键部署），Skill 扫描 CLI 接入 CI/CD 是最实用的单点（对齐 OWASP ASI04）；② AgentOS 建设者——其对齐 SkillTrustBench 的风险分类可作为技能市场准入的参考基线；③ 注意事项——内网部署、勿用生产 API key 做越狱评测（消耗额度且留痕）；④ 跟踪点——LLM API 投毒检测的规则演进，以及与 SkillSpector/agent-scan 的检测规则分化（三家规则库的分歧点本身就是高价值情报）。
