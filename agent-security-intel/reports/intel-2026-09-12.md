### 🔍 深度分析

**是什么**：Prismor（自托管 AI agent 运行时控制平面，Apache-2.0）再次登顶当日活跃榜——三日内两次霸榜，Star 增长与推送频率持续。它在工具调用执行前介入，提供观察/人工审批/阻断三档裁决，拦截秘密外泄、提示注入、供应链投毒，本地 dashboard、策略自定义、对 Claude Code/Codex/LangChain 等框架通用。

**技术机制**（结合本情报线 09-10 的源码级拆解 docs/prismor-rules-and-runtime.md）：① 六表面集成（hooks/MCP gateway/框架 adapter 等）规范化为统一事件，81 条内置规则（16 类阻断，供应链与记忆投毒占三分之一）；② 三层判定（硬规则/内容检测/可逆性一票否决）+ 语义守卫（启发式加权评分可选 LLM 终裁）；③ hash chain + Ed25519 证据链，策略三层合并存在不可覆盖底线。

**证据强度**：活跃工程（非论文，无同行评审概念），81 条规则经过真实误报迭代（如 markdown 行内代码误杀的 #144 修复）；无独立安全评估，控制平面自身仍是用户态进程。

**四层定位与趋势判断**：L2 运行时裁决层的旗舰样本。本周的学术侧呼应是 CCS'26 的 Your Agent Is Mine（LLM 中转供应链攻击测量）：该论文实测「客户端侧防御都是白名单式的、对自适应攻击者 100% 可绕过」——恰好从学术侧框定了 Prismor 类工具的能力边界与价值：降低暴露有效（fail-closed 策略门 + 证据链），但「裁决组件自身可信」仍无硬件锚点。两次霸榜 + 论文背书 = 运行时裁决层从新品期进入标配期的信号。

**影响与对策**：① Agent 系统建设者——observe 模式灰度先行，重点开 destructive/secret-exfiltration/自保护类；② 防御者——把 Prismor 的证据链接到独立存储（链头锚 TPM 是最低成本改造）；③ 跟踪——其「不可覆盖底线集」何时硬件化（TEE/安全岛下沉）是我们方案的第一观察点。
