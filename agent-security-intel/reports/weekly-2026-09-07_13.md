## §2 五条主题线（本周收敛结论）

### 线 1 · L2 运行时安全：单品期结束，套件期进行
榜单四天连续验证"四象限"格局：**运行时裁决**（Prismor，两期 Top1）、**egress 防火墙**（pipelock，常驻）、**上架前静态扫描**（SkillSpector ⭐17k / mcp-triage）、**平台化聚合**（AI-Infra-Guard ⭐6.2k，三期在榜）。学界同步：CONTINUITY（安全上下文契约）、Key-Isolated Threshold Signing 与 Prismor 的能力令牌同构。**软肋共识：检测器质量无独立基准**——谁先发布检测评测，谁定 L2 的规则话语权。

### 线 2 · 证明语义缺口：三线共指，证据在累积
一周内三个独立信源攻击"纯软件证明"的不同前提：**ROS 2 信任边界**（09-09 Top1：单环境变量击穿远程证明——遥测前提）、**TEE 构建不可复现**（09-11 Top1，🏆 CCS'26：度量是二进制的指纹，不是审过源码的指纹——度量前提）、**Your Agent Is Mine**（🏆 CCS'26：LLM 路由器中间人调包 tool call——来源前提，客户端防御对自适应攻击 100% 可绕过）。**"硬件抓手立项论据"从单点观察升级为三条正交证据线**。新增待收敛关键词：`provider response signing` / `canonical response envelope`。

### 线 3 · 硬件抓手：从方案推导到产业迹象
一周内完成"推导闭环 + 产业验证"双重进展：推导侧产出三域模型/三件套/两段式 AOT/契约下发接口（hardware-enforcement-scheme.md + 13 页 deck）；产业侧三个信号——**OpenHarmony iTrustee REE lite（"TEE agent service"，华为官方）**、**vla-shield**（模型无关 VLA 安全过滤层，与 Cudro 同位）、**aptos 机密推理路由器**（TDX CVM 部署工件）。具身安全过滤器赛道一周三现（含终身 VLA 能力侧共振）——**主题热度拐点确认**。

### 线 4 · 供应链攻击实战化（Anthropic 威胁报告周）
09-12 完成Anthropic 半年报（154 页、七章 33 案例）的完整解读（docs/anthropic-threat-report-2026-09.md）。与我们情报线互证最深的三点：**AI 供应链成为蓄意犯罪目标**（API key = 赃物+算力+掩护三合一；评估沙箱被注入掏生产密钥）、**恶意 agent 编排化**（GTG-10007 漏洞工厂：agent 蜂群/持久战役记忆/单月十余疑似零日；GTG-20006 恶意软件被检出后 AI 自主改型）、**蒸馏攻击点名**（DeepSeek/Moonshot/Zhipu/小米，跨会话重放抽 CoT）。防御启示：静态检测的时代性贬值、agent 环境与高权凭证必须隔离域。

### 线 5 · 情报基建本身建成（本周的"元主题"）
从 09-07 的板块式报告演进为：Top10 关键信息榜单制 + 模型三段分析（Top1 深读/Top2-10 简评/趋势点评）+ 幂等填充 + 顶会双通道（arXiv comment 🏆 + 官网列表）+ 精读增量（Atom feed，静默零成本）+ 一手技术源 8 家。**本周修复的四个真 bug**：RSS 时区后缀导致时间窗失效（1842→139 条）、精读提交词边界（"rom"误命中"from"）、GitHub issues.atom 关停适配、NDSS 假基线（2017 旧页面，已停用该源）。
