# 超级小工具平台 · 开发指南（面向 AI Agent 与开发者）

> 本文档是平台的权威开发规范。AI 助手在此平台上开发时，**必须先读完本文**；
> 摘要版见 `skills/super-tools-dev/SKILL.md`。

## 0. 平台是什么

前后端分离的内部工具平台：后端 FastAPI + SQLAlchemy，前端 Vue3 + Element Plus，
核心机制是**模块自动发现**——新增小工具 = 加目录 + 注册一行，**不改任何框架文件**。

```
浏览器 → nginx(80) → ┬─ /      静态文件（Vue 构建产物）
                     └─ /api/* → uvicorn(127.0.0.1:8000) → PostgreSQL / SQLite
```

| 路径 | 说明 |
|---|---|
| `server/app/main.py` | 框架入口：登录/统计/中间件/挂载工具路由 |
| `server/app/registry.py` | **模块自动发现**（扫描 modules/ 下的目录） |
| `server/app/modules/<工具名>/` | 每个工具一个目录（router.py 必需，models.py 可选） |
| `server/app/modules/_template/` | 复制模板（下划线开头不会被加载） |
| `server/app/crud.py` | **公共数据模块**：任意表增删改查/导入/导出 |
| `server/app/{auth,db,config,models}.py` | 认证(JWT)/数据库会话/配置/用户与日志表 |
| `web/src/modules/<工具名>/` | 前端工具页面；`registry.js` 注册 |
| `web/src/{layout,views,api,store,router}.js` | 框架：布局/登录/管理面/axios/登录态/路由守卫 |
| `server/tests/`、`web/tests/` | 测试（发布脚本会强制跑） |
| `deploy/` | 部署工程：deploy.conf(占位符配置)+模板+package.sh+install.sh |

业务面 `/`（工具门户）与管理面 `/admin`（独立登录，仅管理员）分离。

## 1. 环境与命令

```bash
# 后端（server/ 目录）：python3.10+
python -m venv venv && venv/bin/pip install -r requirements.txt -r requirements-dev.txt   # Windows: venv\Scripts\pip
venv/bin/python -m pytest          # 测试
venv/bin/python -m uvicorn app.main:app --reload --port 8000   # 开发运行

# 前端（web/ 目录）：node 18+
npm install && npm run dev         # 开发（/api 自动代理到 localhost:8000）
npm run test && npm run build      # 测试 + 构建
```

配置通过环境变量或 `server/.env`（`DATABASE_URL/JWT_SECRET/LOG_RETENTION_DAYS/STATIC_DIR`），
`.env` 不进 Git；测试夹具会自动使用独立 SQLite，无需配置。

## 2. 新增一个小工具（标准三步）

### 第一步：后端模块

复制 `server/app/modules/_template/` 为 `server/app/modules/<工具名>/`：
目录名 = URL 前缀 = 菜单标识，**英文小写+下划线，全站唯一，必须保留 `__init__.py`**。

`models.py` —— 数据表（没有表也可以不要此文件）：

```python
from sqlalchemy import Integer, String, Text, Float, Boolean, DateTime, Date
from ...db import Base

class Price(Base):
    __tablename__ = "prices"                      # 表名全站唯一
    id = mapped_column(Integer, primary_key=True)
    material = mapped_column(String(100))         # 必填
    price = mapped_column(Float, default=0)       # 可空给 default
```

`router.py` —— 接口（**每个接口必须带 `Depends(get_current_user)`**）：

```python
from fastapi import APIRouter, Depends
from ...auth import get_current_user
from ...crud import list_rows, create_row, update_row, delete_row   # 公共模块，别手写CRUD
from ...db import get_db
from ...models import User
from .models import Price

TOOL = {
    "title": "物料查价",                    # 门户菜单名
    "importable": False,
    "tables": {"prices": "价格表"},          # 声明后自动进管理面"数据管理"
}
router = APIRouter()

@router.get("")
def list_prices(skip: int = 0, limit: int = 50, keyword: str = "",
                user: User = Depends(get_current_user), db=Depends(get_db)):
    return list_rows(db, Price, skip=skip, limit=limit, keyword=keyword)

@router.post("")
def create_price(data: dict, user: User = Depends(get_current_user), db=Depends(get_db)):
    return create_row(db, Price, data)

@router.put("/{row_id}")
def update_price(row_id: int, data: dict, user: User = Depends(get_current_user), db=Depends(get_db)):
    return update_row(db, Price, row_id, data)

@router.delete("/{row_id}")
def delete_price(row_id: int, user: User = Depends(get_current_user), db=Depends(get_db)):
    return delete_row(db, Price, row_id)
```

重启后端即自动挂载到 `/api/tools/<工具名>/...`，无需注册。

### 第二步：前端页面

复制 `web/src/modules/_template/TemplateView.vue` 到 `web/src/modules/<工具名>/`，
把 `<工具名>` 占位替换掉，然后在 `web/src/modules/registry.js` 加一行：

```js
export const registry = {
  notes: () => import('./notes/NotesView.vue'),
  '<工具名>': () => import('./<工具名>/XxxView.vue'),   // ← 加这行
}
```

前端约定：请求一律走 `api`（`web/src/api.js`，自动带 token、401 自动跳登录）；
列表接口统一消费 `{"total", "items"}`；消息用 `ElMessage`，删除前 `ElMessageBox.confirm`。

### 第三步：测试（必须写）

在 `server/tests/` 加 `test_<工具名>.py`，参考现有测试：

```python
def test_price_crud(client, admin):
    r = client.post("/api/tools/<工具名>", json={"material": "screw", "price": 1.5}, headers=admin)
    assert r.status_code == 200
    r = client.get("/api/tools/<工具名>", params={"keyword": "screw"}, headers=admin)
    assert r.json()["total"] == 1
```

夹具：`client`(TestClient)、`admin`(管理员头)、`business`(业务用户头)。
**发布脚本会先跑全部测试，测试不过无法发布。**

## 3. 框架能力清单（可直接复用，不要重复造）

| 能力 | 位置 | 用法 |
|---|---|---|
| 任意表 CRUD/搜索 | `app.crud.list_rows/create_row/update_row/delete_row` | 见上文模板 |
| CSV/XLSX 导入 | `app.utils.importer.read_rows(file)` → `list[dict]` | 表头=列名 |
| 全表导出 | `app.crud.export_bytes(db, Model, "csv"\|"xlsx")` | 返回 (bytes, mime, 文件名) |
| 批量导入 | `app.crud.import_rows(db, Model, rows)` | 非法行跳过并计数 |
| 类型转换 | `app.crud.coerce({"kind":...}, value)` | 字符串→int/float/bool/datetime |
| 列元信息 | `app.crud.table_columns(Model)` | 前端动态表格/表单用 |
| 鉴权 | `Depends(get_current_user)` / `Depends(require_admin)` | 业务/管理接口 |
| 数据库会话 | `Depends(get_db)` | |
| 访问日志 | `access_logs` 表（中间件自动写） | 免维护，90 天自动老化 |

**管理面已有能力（勿重复开发）**：用户管理、使用统计看板、任意工具表的数据管理
（分页/搜索/行级增删改/导入导出），API 前缀 `/api/admin/*`，全部仅管理员。

## 4. 打包与部署（工程化流程）

```bash
# 本地一键打包（GitBash/Linux）：跑全部测试 → 构建前端 → 产出 release/super-tools-<版本>.tar.gz
bash deploy/package.sh

# 安装（一次性，上环境）：解压发布包，进入目录后
cp deploy/deploy.conf.example deploy/deploy.conf   # 填写 __XXX__ 占位符（部署位置、数据库等）
sudo bash deploy/install.sh                        # 建库→渲染配置→注册服务→起服务

# 升级（可重复执行）：代码同步→依赖→测试门禁→静态文件→重启→健康检查
sudo bash deploy/upgrade.sh                        # 保留 server/.env 与数据；测试不过自动中止
```

# Windows 同理：deploy\windows\deploy.conf(.example) + install-windows.ps1（安装）/ upgrade-windows.ps1（升级）
```

要点：
- **部署位置全部在 deploy.conf 用占位符声明**（APP_HOME/WEB_ROOT/SERVICE_NAME/RUN_USER/SERVER_PORT/NGINX_CONF），install.sh 渲染 `deploy/templates/` 下的 systemd/nginx 模板
- **数据库等敏感配置单独落在 `<APP_HOME>/server/.env`**（不进 Git、不在模板里），`DB_MODE=postgres|sqlite` 切换，JWT_SECRET 留空自动生成
- 发布包含**预构建前端**，目标机器无需 node
- `DRY_RUN=1 bash deploy/install.sh` 可先校验配置并输出渲染结果，不动系统

## 5. 红线约定（违反=必须整改）

1. **禁止修改框架文件**：`main.py`、`registry.py`、`crud.py`、`auth.py`、`db.py`、`router.js`、`api.js`、`store.js`、两个 Layout——需要扩展框架能力时，先在本文档补规范再动
2. 表名、模块目录名全站唯一；列表返回 `{"total", "items"}`；所有接口必须鉴权
3. 新代码必须带测试；提交前 `pytest` 与 `npm run test` 全绿
4. **SPA 前端改动发布后必须真实浏览器验证**（curl 验证不了路由/渲染）
5. 不要在仓库提交任何密码/密钥/.env；数据库操作走公共模块，不要手写裸 SQL 字符串拼接

## 6. 已知坑（前人踩过）

- PostgreSQL 没有 `date()` 函数，`GROUP BY` 必须显式列出非聚合列——日期聚合在 Python 侧做
- 工具目录漏 `__init__.py` 会导致模块静默不被发现（registry 跳过导入失败者）
- nginx `cp` 到非空目录会堆积旧 hash 资源，发布要先清空 WEB_ROOT
- index.html 必须 `no-cache`，否则发版后浏览器用旧入口页
- 路由守卫不能把目标重定向到与当前相同路径（无限重定向=白屏）
- Windows ARM 没有 psycopg2 预编译包，PG 驱动只在 postgres 模式安装（requirements-postgres.txt）
